# INSTRUCCIONES
En la carpeta `Laboratorio 1` se encuentra el Frontend que consume los endpoints del Backend correspondiente al laboratorio 1. Adicionalmente, en el Backend se incluyeron las operaciones de eliminar y actualizar la información del cliente en el servicio y controlador, junto con las instrucciones para que el Backend pueda recibir las peticiones del Front.
Únicamente es necesario copiar el repositorio y correr el backend. En el caso del front, ejecutar `npm install` para instalar los modulos necesarios,  y `npm run dev`  para correrlo en el puerto 5173.
